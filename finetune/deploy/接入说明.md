# 微调模型接入项目说明

目标：把训练好的 Qwen2.5-7B 医学问诊模型接入 intelligent_consultation，替换线上 `deepseek-ai/DeepSeek-V3`。项目的 LLM 接入层（`backend/app/services/llm_service.py`）走 OpenAI 兼容协议，**只改 `backend/.env` 三个变量即可完成切换，无需改任何代码**。

## 路线 A：ollama（Windows 本机最简单，推荐练手）

### 1. 合并 LoRA → 完整模型（在 finetune/ 目录）

```bash
llamafactory-cli export configs/merge_export.yaml
# 产物：finetune/models/qwen2.5-7b-medical-sft/
```

### 2. 转 GGUF 并量化

```bash
# 安装 llama.cpp（或下载预编译版）
git clone https://github.com/ggerganov/llama.cpp
cd llama.cpp && pip install -r requirements.txt

# 转 GGUF（fp16，约 15GB）
python convert_hf_to_gguf.py ../finetune/models/qwen2.5-7b-medical-sft --outfile qwen2.5-7b-medical-sft-f16.gguf

# 量化到 Q4_K_M（约 4.7GB，效果损失很小）
cmake -B build && cmake --build build --config Release
./build/bin/llama-quantize qwen2.5-7b-medical-sft-f16.gguf qwen2.5-7b-medical-sft-q4_k_m.gguf Q4_K_M
```

### 3. 注册 ollama 模型

把 `qwen2.5-7b-medical-sft-q4_k_m.gguf` 放到本目录（finetune/deploy/），然后：

```bash
ollama create qwen2.5-7b-medical-sft -f Modelfile
ollama run qwen2.5-7b-medical-sft "高血压有什么症状？"   # 冒烟测试
```

### 4. 切换项目配置

编辑 `backend/.env`：

```ini
SILICONFLOW_BASE_URL=http://localhost:11434/v1
SILICONFLOW_MODEL=qwen2.5-7b-medical-sft
SILICONFLOW_API_KEY=ollama
```

> API_KEY ollama 不校验，但项目配置要求非空，随便填即可。
> 语义缓存按 model 键控，换模型后缓存自动隔离，无脏数据风险。

### 5. 重启后端验证

```bash
cd backend && uv run uvicorn app.main:app --reload
```

前端发起问诊对话，观察回答是否带 [来源] 标注、免责声明。视觉模型（Qwen2.5-VL）和嵌入模型（bge-large-zh）走独立配置，不受影响。

## 路线 B：WSL2 + vLLM（bf16 原精度，效果最好）

```bash
# WSL2 内
pip install vllm
vllm serve /mnt/c/.../finetune/models/qwen2.5-7b-medical-sft --served-model-name qwen2.5-7b-medical-sft --port 8000 --max-model-len 4096
```

`.env` 改为：

```ini
SILICONFLOW_BASE_URL=http://localhost:8000/v1
SILICONFLOW_MODEL=qwen2.5-7b-medical-sft
SILICONFLOW_API_KEY=empty
```

vLLM 原生支持流式输出（SSE），与项目 `stream_generate` 完全兼容。

## 回滚

把 `.env` 三个变量改回硅基流动即可：

```ini
SILICONFLOW_BASE_URL=https://api.siliconflow.cn/v1
SILICONFLOW_MODEL=deepseek-ai/DeepSeek-V3
SILICONFLOW_API_KEY=<原Key>
```

## 已知边界

- 微调模型训练语料以项目 KG/指南为锚点，回答范围围绕 13 种疾病与两篇指南；超纲问题模型应回答"暂无明确指南支持"——这正是训练目标，不是缺陷
- `entity_recognizer` 的 LLM 调用走同一个 llm_service，也会切到微调模型（训练里包含 800 条 NER 样本，输出契约对齐）
- 图片分析（image_analysis.py）与表格/图片描述生成器使用独立 client + 视觉模型，不受切换影响
